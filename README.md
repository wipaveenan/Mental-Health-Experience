# OOCA Mind Check-in — ถ้าพรุ่งนี้ตื่นมาแล้วรวย คุณจะทำอะไร?

เว็บแอปพลิเคชันแบบทดสอบสำรวจความต้องการลึก ๆ ของใจผ่าน 5 คำถามสั้น ๆ (Micro Self-Reflection) ออกแบบตามระบบสี CI ของ OOCA (`#80E2D9`, `#00C4B3`, `#1F77DF`, `#FCF4E0`) พร้อมแอนิเมชัน (Motion) ของตัวละครทุกตัว

## ฟีเจอร์และกรณีที่รองรับครบตาม Flowchart
1. **หน้าแรก (Intro Screen)**: พื้นหลังไล่เฉดสี `#80E2D9` พร้อมตัวละคร `Sunny Friend` ลอยตัวเบา ๆ บนเบาะสีเหลืองพาสเทล และเอฟเฟกต์เมื่อคลิกทักทายตัวละคร
2. **หน้าคำถาม 5 ข้อ (Questions 01–05)**:
   - เลือกคำตอบ 1–5 ตามความรู้สึกแรก
   - มีปุ่ม **ข้ามข้อนี้ (Skip)** ในทุกข้อ โดยข้อที่ข้ามจะไม่นำมานับคะแนน
   - มีปุ่มลิงก์ **ช่วงนี้หนักเกินกว่าจะตอบ** ในทุกหน้า
3. **ระบบประมวลผลคะแนน (Scoring Engine)**:
   - **ผลชัดเจน (เลือกหมวดเดิมซ้ำ 4–5 ครั้ง)**: แสดงหน้าสรุปผลตามหมวดอันดับ 1 (1 พัก `Moon Dreamer`, 2 อิสระ `Balloon Explorer`, 3 มั่นคง `Bench Break`, 4 เชื่อมโยง `Curious`, 5 ได้รับการดูแล `Glowing Heart`) พร้อมก้าวเล็ก ๆ วันนี้ที่ไม่ใช้เงิน และปุ่มคุยกับผู้เชี่ยวชาญ OOCA ที่เด่นชัด
   - **ผลผสม (เลือก 2–3 ครั้ง) หรือคะแนนเท่ากัน**: แสดงหน้าสรุปหลายผลลัพธ์ (2 อันดับแรกคู่กัน) พร้อมตารางความหมายและก้าวเล็ก ๆ ทั้ง 5 หมวด
4. **หน้าดูแลใจฉุกเฉิน (ช่วงนี้หนักเกินกว่าจะตอบ)**: พาเข้าสู่พื้นที่พักใจทันทีโดยไม่คำนวณคะแนน พร้อมปุ่มโทร **สายด่วนสุขภาพจิต 1323** และปุ่มปรึกษาผู้เชี่ยวชาญบน OOCA

## วิธีนำไปขึ้น GitHub Pages
1. อัปโหลดไฟล์ `index.html` (และโฟลเดอร์ `svg_screens/` หากต้องการเก็บไฟล์ออกแบบอ้างอิง) ขึ้นไปยัง GitHub Repository ของคุณ
2. ไปที่ **Settings > Pages** เลือก Branch `main` (โฟลเดอร์ `/root`) แล้วกด **Save**
3. เว็บไซต์พร้อมใช้งานทันทีทั้งบนมือถือและคอมพิวเตอร์โดยไม่ต้องติดตั้งไลบรารีเพิ่มเติม
